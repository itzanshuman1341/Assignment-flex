# 🎨 CSS Flexbox Layout

A simple **HTML & CSS Flexbox project** created to practice and demonstrate how **Flexbox** can be used to build webpage layouts.

## 📌 Project Overview

This project creates a structured webpage layout using HTML and CSS. It contains:

* 📄 Header section
* 🖥️ Main/center section
* ◀️ Left section
* ▶️ Right section
* ⬆️ Top section
* ⬇️ Bottom section
* 🔲 Two nested bottom sections
* 📄 Footer section

The main center area uses `display: flex` to arrange its child elements horizontally.

## 🛠️ Technologies Used

* **HTML5**
* **CSS3**
* **CSS Flexbox**
